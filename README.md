# VilageVibe - Landing Page de Viagens 🏔️

Este projeto é uma landing page moderna e responsiva focada no vilarejo de Hallstatt, na Áustria. Desenvolvida como parte de um desafio de Front-End para praticar semântica HTML, CSS avançado e UX/UI.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estrutura semântica e acessibilidade.
- **CSS3**: Layouts em Grid e Flexbox, variáveis CSS e efeitos de hover.
- **JavaScript**: Funcionalidade de scroll suave e botão "Voltar ao topo".

## 🎨 Diferenciais do Projeto
- **Estética Silent Luxury**: Design limpo com foco em tipografia e respiro visual.
- **Experiência do Usuário (UX)**: Navegação fluida e micro-interações em imagens.
- **Performance**: Galeria de imagens otimizada para carregamento leve.

## 🛠️ Como executar
1. Clone o repositório.
2. Abra o arquivo `index.html` com a extensão Live Server no VS Code.
